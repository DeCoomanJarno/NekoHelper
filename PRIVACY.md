# Privacy Policy: NEKO Helper

Last updated: 09/11/2026

NEKO Helper helps users prepare timesheet entries on the NEKO site.
The extension stores its settings, project configuration, and offline test entries in the browser's extension storage. It does not send this information to the extension publisher, and it does not use analytics or advertising services. Importing and exporting settings or offline entries is initiated by the user.
On the live NEKO site, the extension prepares fields in NEKO's existing form. The user reviews the entries and submits them using NEKO's Save button. NEKO then receives and processes the submitted entries under the user's organization's arrangements. The extension does not read or store passwords, session identifiers, or CSRF tokens.
The extension does not load remote executable code.
